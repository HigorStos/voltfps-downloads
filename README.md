# VoltFPS para Windows

Este repositório reúne os instaladores Windows x64 e os metadados de atualização do VoltFPS.

- [Baixar a versão mais recente](https://github.com/HigorStos/voltfps-downloads/releases/latest)
- [Histórico de versões](https://github.com/HigorStos/voltfps-downloads/releases)

Na primeira instalação, abra o arquivo `VoltFPS_*_x64-setup.exe` disponível na release. O botão **Atualizar** aparece na conta quando houver uma versão mais nova.
